## Current Verification Surface

- `backend/package.json` has no automated `test` script; it intentionally exits with an error.
- `backend/test-score.js` is a manual end-to-end script that expects a running Node server, database, reference upload, and CLIP path.
- `clip_service/test_scoring.py` is a manual comparison script that loads CLIP and fetches remote images; it is not an isolated unit test.
